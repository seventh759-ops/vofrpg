# 0.9.1 の変更点（前回のAPK＝11/19 の作業のあとから）

## 見た目（絵）
- **街の立ち絵**：全16種類を新しいドット絵に差し替え（灯術師・炎呼び・焔王・灯台守・星守／影刃・夜狩り・日蝕・血刃・血の君主／灯番・陽縛り・暁光・城壁・神盾／彩灯者）。絵の大きさが違っても同じ背の高さで表示。
- **ダンジョンのキャラ（SD）**：全16種類を新しい 32×48 の絵に差し替え（自動の陰影なしで、絵の色そのまま）。背は約1.5マス。
  - 歩くときは片足を持ち上げる（足が切れない）。分身・頭の上の文字・光の羽なども、背の高さに合わせて位置を調整。
- **アプリのアイコン**：灯術師とランタン、下に「VoF」の文字。角丸の形。
- **彩灯者の通常攻撃**：色とりどりの結晶の弾（小さめ）。

## ダンジョンの画面と操作
- 右手／左手の切り替え（設定「操作：右手／左手」）。技のボタンが親指の側に寄る。
- 下段を1段にまとめ、枠をなくして後ろにロゴを薄く。3つのボタンは低くし、その上に「H：操作」（PCのみ）。空の技の枠は塗りつぶし。
- 「押す間」のときの攻撃ボタンを小さく。ダンジョンの表示を少し上へ。
- 上段：街と同じ形の情報カード（HP/MP と階、Lv の円と EXP の輪、火種・欠片と回避のバー）。文字は通常のフォント。
- メッセージは枠なしでダンジョンに重ねる。地図は上段のすぐ下、メニューは地図の下の歯車。
- バフ・デバフの印は下段のすぐ上に小さく。
- ボスの体力バーはダンジョンの下の方（薬のボタンの上）。

## 街の画面
- 画面を作り直し：上は情報カード、案内役のあいさつ、中央に台座の上の立ち絵、下に扉の「出撃」、左右に能力値・キャラ選択・スキル・荷運び、最下段に倉庫・ショップ・鍛冶・カバン・女神。
- カバンのアイコンを肩掛けの鞄に。
- 鍛冶：画面を作り直し。
  - 品を選ぶ画面：装備中と持ち込む品を同じ大きさのマスで並べ、選んだ品は金の枠。下に説明と「強化／効果を再抽選／部位を変える・合成」のボタン。
  - 強化の画面：左に強化する装備、右に素材にする装備（+10・+15 のときだけ。タップで選ぶ）。強化したあとの値と条件（✔）を表示し、そろったら「火種 ○ で強化する」。
  - 効果の再抽選は専用の画面（残す効果に錠をかけて引き直す）。

## 演出・音
- 珍しい品が飛び出したとき：スロー、ダンジョン部分の縁の淡い光と、またたく小さな光。
- ドロップの演出は光の粒だけ（輪・柱・画面の色づきはなし）。
- 輪は「攻撃が届く範囲」と「敵の攻撃の予告」だけ。ポーション・レベルアップ・階段・泉・祭壇・宝箱・区画に入ったときなどは、光の粒や柱に。
- 神話・ボスのセットの品が落ちたときの音：「キンキン」と鳴る大当たりの音。
- 転生の印：足元の輪を薄く、キャラのまわりに転生の色のきらめき。
- 転職・3次職・転生のお祝いの画面、レベルアップの演出を大きく。

## 遊び方・バランス
- **中断した挑戦**：起動したとき、中断データがあれば「続ける／やめる」だけを聞く（中断したときの場所・HP・火種・鞄などを表示。やめるときは確認あり）。中断できるのは1キャラクターだけ。
  - 中断したまま町で転職して、転職前の装備で続きを遊べてしまう問題を防ぐため。
- **昇る塔（女神に捧げたあと）を難しく**：1層の敵を Lv10 相当 → Lv24 相当に、昇る塔・天界の敵は体力1.6倍・攻撃1.4倍。もらえる経験値は前のまま。
- 序盤（5〜20階）の敵の攻撃を強め、ボスと精鋭も硬く。
- 能力値の画面に「職」の欄（職の特徴・主／副の能力値・武器・技・成長の道筋）。職の選択画面に灯りの適性の一文。
- 転職・転生で使えなくなった装備は、まずカバンへ（入らない分だけ倉庫へ）。

## プロローグ
- タイトルのあと、失われた光と女神像の物語を一度だけ表示（設定から見直せる）。長い行は折り返す。

## 不具合の修正
- 街に戻ったとき・キャラを選び直したときに、HP/MP が古い値のまま表示されていたのを修正。
- Android のビルドが失敗していたのを修正（取り込んだ絵のデータの持ち方を変更）。
