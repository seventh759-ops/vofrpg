## 0. 前提

- 【決定】ジャンル：**ローグライク・ハクスラ**（リアルタイム）。**ドロップが大量に出る爽快感（ドパ要素）を込みにする**
- 【決定】対象：Android と PC。iPhone は Mac がないため後回し（第8章）
- 【決定】エンジン：Unity 6 LTS 系
- 【決定】規模：小さく1本。初クリアまで約1時間
- 【決定】見た目：ドット絵。タイルは 16×16 で一旦進める
- 【決定】操作：縦持ち片手。移動と回避は手動。通常攻撃は「自動」と「押している間だけ」を設定で選べる。スキルは手動か、クールダウン明けの自動発動かを選べる
- 【決定】持ち帰り：C寄りのB（帰還すれば複数の装備を持ち帰れるが、数に上限がある。4.5）
- 【保留】暗いことの強み：遊んでみてから決める
- 【決定】明るさ：全員共通の基本値から始め、スキルやアイテムで広げる。体力とは連動させない
- 【決定】Unityプロジェクトはこのリポジトリ（vofrpg）に置く

【決定】「ドパ要素」＝倒すとアイテムや火種がドバッとあふれ出し、レアが出た瞬間に気持ちいいこと。

## 1. コンセプト【案】

**【決定】タイトル：『Vivid of Fade（ヴィヴィッド・オブ・フェイド）』**（略称 VoF。リポジトリ名 vofrpg と合わせる）

暗い塔を下りながら、押し寄せる敵の群れをなぎ倒し、あふれ出る装備を拾って自分だけの組み合わせを作るハクスラ。

- 気持ちよさの柱
  1. **群れをまとめて倒す**：画面いっぱいの敵を一気に消し飛ばす
  2. **ドロップの噴水**：強い敵や宝箱から装備と火種があふれ出る
  3. **レアの瞬間**：光の柱・専用の音・画面の揺れで「当たり」を知らせる
  4. **組み合わせが壊れる**：装備の効果が重なって、急に強くなる瞬間がある
- 明るさは**装備の能力の一つ**として残す。明るさの範囲＝見える範囲＝自動攻撃の届く範囲

## 2. 操作（スマホ・縦持ち）【案】

| 操作 | 方法 |
| --- | --- |
| 移動 | 画面を親指で押してずらす（押した場所が仮想スティックの中心） |
| 通常攻撃 | 設定で選ぶ。「自動」：常に明るさの範囲内の敵を狙う／「押している間だけ」：攻撃ボタンを押している間だけ撃つ（狙い方は装備で変わる） |
| 回避 | 画面をはじく。短い無敵時間あり |
| スキル | 画面下のボタン（最大3つ）。スキルごとに「手動」「オート」を切り替え |
| 拾う | 近づくだけで自動で吸い寄せる。装備は自動で鞄へ入る |
| 装備の入れ替え | 一時停止して鞄を開く。今の装備より強いものには矢印を出す |

PC版はキーボード（WASD／矢印、回避はスペース、スキルは1〜3、鞄はTab）とゲームパッドに対応する。

## 3. ゲームの流れ

```
拠点（塔の入口）
 └ 出撃 → 第1層 → 第2層 → 第3層 → 第4層 → 最下層（ボス）
            各層：群れとの戦闘 → 精鋭・宝箱でドロップの噴水 → 祭壇 → 下り階段
 └ 死亡／クリア → 拠点へ戻る（持ち帰れるものは 4.5）
```

| 項目 | 目安【案】 |
| --- | --- |
| 1回の挑戦 | 12〜15分 |
| 初クリアまで | 3〜5回の挑戦（約1時間） |
| 層の数 | 5層（4層＋ボス層） |
| 1層の構成 | 広めの部屋4〜6個。部屋に入ると敵の波が来る |
| 画面内の敵 | 通常 30〜60体、多い場面で 100体前後 |
| 中断 | アプリを閉じても、その層の最初から再開できる |

## 4. 主な仕組み【案】

### 4.1 装備
- 装備欄は5つ：**武器／ランタン／防具／指輪×2**
  - 武器：通常攻撃の形が変わる（単発・連射・扇状・貫通の槍など）
  - ランタン：明るさと、火の属性（炎・氷・雷・影）を決める
- 珍しさは5段階。色で区別する

| 段階 | 色 | 付く効果 | 出る頻度（目安） |
| --- | --- | --- | --- |
| 並 | 白 | 0〜1個 | とても多い |
| 良 | 青 | 1〜2個 | 多い |
| 稀 | 黄 | 3〜4個 | ときどき |
| 伝承（Legendary） | 紫 | 3個＋固有効果1つ | まれ |
| 灯宝（Relic） | 橙 | 2個＋固有効果2つ。組み合わせを大きく変える | とてもまれ |
| 神話（Mythic） | 赤 | 4個＋固有効果1つ＋ボス専用の固有効果1つ。武器だけ主能力の必要値がある | ボスから30%、黄金のスライムから10%、精鋭から3% |

- 効果の例：攻撃力＋%、攻撃速度＋%、明るさ＋1、会心率、移動速度、スキルのクールダウン短縮、倒した敵が爆発する、拾った火種で回復、など。初回は30種類程度
- 固有効果の例：「通常攻撃が3回に1回、スキルの火の輪を出す」「明るさの外の敵にもダメージが届く」「回避した場所に火の柱が残る」

### 4.2 ドパ要素（演出と仕組み）
- **ドロップの噴水**：精鋭・宝箱・ボスを倒すと、装備と火種が放物線を描いて一斉にあふれる
- **当たりの演出**：稀以上は光の柱、伝承以上は専用の音と短い画面の揺れ、灯宝は一瞬スローになる
- **黄金の敵**：たまに出る逃げ回る敵。倒すと火種が大量に出る
- **宝の間**：ときどき出る特別な部屋。敵の波を全部倒すと宝箱が並ぶ
- **ダメージの数字**、ヒットストップ（当てた瞬間のわずかな停止）、群れが一気に消える効果音
- **スマホ向けの手間削減**：拾うのは自動、並の装備は自動で火種に変える設定、比較矢印、一括分解

### 4.3 明るさ
- 基本値は全員共通（例：半径3マス）。ランタン・効果・スキルで広げる
- 明るさの外の敵はぼんやり見えるだけで、通常攻撃が届かない
- 明るさを一時的に縮める敵（闇撒き）がいる

### 4.4 スキル・祭壇
- スキル：最大3つ。宝箱や祭壇で手に入る。例：火の輪、灯矢、照らし（数秒だけ明るさを大きく広げる）、火柱。初回は6種類
- 祭壇：火種を払い、3つの強化から1つ選ぶ（その挑戦のあいだだけ有効）。初回は12種類

### 4.5 持ち帰れるもの【決定：C寄りのB／細部は案】
- 各層の階段の前で「**下りる**」か「**帰還する**」かを選べる。最下層のボスを倒したときも帰還になる
- 帰還すると、鞄の中から**持ち帰り枠の数まで**装備を選んで倉庫へ送れる。残りは火種に変わる
- 持ち帰り枠は**3つ**から始まり、拠点での解放で最大**8つ**まで増える【数は案】
- **死亡すると**、その挑戦で拾った装備はすべて失う。挑戦に持ち込んだ装備は失わない【案】
- 倉庫の装備は、次の挑戦で装備欄に付けて持ち込める
- 狙い：「もう1層下りてもっと良い物を狙うか、今のうちに帰って確保するか」の駆け引きを作る

**試作での形（波が続く部屋）【決定・M4で層に合わせて作り直す】**
- ボスを倒した直後（10波ごと）に「帰還する／続ける」を選ぶ
- 帰還：装備中の5つと、前回から持ち込んだ品はそのまま。今回拾った品からは**3つまで**選んで持ち帰る。火種も持ち帰る
- 死亡：今回拾った品はすべて失い、挑戦を始めたときの装備と倉庫に戻る
- 次の挑戦は、前回帰還したときの装備を付け、倉庫の品を鞄に入れた状態で始まる（職業ごと）
- Lvリセットをすると、付けていた装備は倉庫へ移る

### 4.5.1 火種の使い道【決定：計画どおり M4・M5 で作る】
- M4：各層の祭壇で火種を払い、強化を選ぶ
- M5：持ち帰って拠点での解放に使う
- 追加の候補（未決定）：装備のレベル上げ、効果1つの振り直し、珍しさの格上げ

### 4.5.2 職業【決定】
- 3職業。**挑戦の開始時に選ぶ**。試作中は**最初から全部選べる**
- 武器は**職業専用**。今の職業の武器だけが落ちる（ランタン・防具・指輪は共通）

| 職業 | 通常攻撃 | 武器（3種） | 特徴【数値は案】 |
| --- | --- | --- | --- |
| 灯術師（Lampwright） | 火の玉を撃つ。明るさ＝届く範囲 | 杖（貫通）／連射杖／扇杖（3方向） | 体力100。明るさが広いほど強い |
| 影刃（Shadeblade） | 前方を扇形に斬る | 剣（広い）／短剣（速い・会心）／大剣（遅い・180度） | 体力120、足が速い、会心が出やすい、明るさは狭い |
| 灯番（Warden） | 体の周りを灯りが回る／周りを一度に焼く | 香炉（灯り2つ）／鎖灯（灯り4つ・速い）／火鉢（周りを焼く） | 体力160、防御が高い、足が遅い |

- 弾の数の効果（+1 Projectile）は、影刃では斬る広さ、灯番では灯りの数になる。貫通は灯術師だけに付く
- 影刃の斬撃は、近い順に一度に当たる数に上限がある（剣4・短剣2・大剣6）。2体目以降は威力が半分【数値は案】
- 敵は波が進むほど体力も攻撃力も増える（近接で張り付くほど危なくなる）

### 4.5.3 MMO風味の成長【決定】
2DのMMORPGらしい成長の手触りを入れる（特定の既存ゲームの名前・キャラ・絵・マップ・NPCは使わず、すべてオリジナルにする）。

- **レベルと経験値**：敵を倒して経験値を得る。**レベルは職業ごとに挑戦をまたいで残る**（端末に保存）。死亡時の経験値の減少は後で決める
- **能力値**：STR（力）・DEX（敏捷）・INT（知力）・VIT（体力）・WIS（精神）の5つ。**レベルが上がるごとにポイントをもらい、自分で振る**
  - STR：物理の攻撃力（影刃の主能力）
  - DEX：攻撃の速さ、会心率
  - INT：魔法の攻撃力（灯術師の主能力）。MP は増えない。魔法の職業のスキルは 1 ポイント +1%、単体向け（狙って落とす・弾を撃つ）はさらに +1%
  - VIT：最大体力、体力の自然回復、防御（1ポイントで +0.5。以前は STR だったが、攻めと守りを両立できてしまうので移した）
  - **回復と消費**：攻撃を受けるか与えてから4秒は「戦闘中」で、HP の自然回復は1/4、MP は1/2。吸収で回復できるのは1秒あたり最大 HP の2%まで。スキルの消費 MP は1レベルごとに+2%、後ろのスキルほど1つごとに+12%
  - WIS：灯りの攻撃力（灯番の主能力）、最大MP、MPの自然回復。魔法の職業の範囲スキル（自分のまわり）は 1 ポイント +2%
  - **最大MPの伸び**：レベルアップのたびに、**その時点のWIS（振った分＋職業の初期値。装備は数えない）**で上限が積み上がる（2 + WIS÷3）。MPが欲しければ先にWISを振る。振り直しても積み上がった分は残り、Lvリセットで0に戻る。今のWISからも少し（WIS×2）増える
- **MP**：体力とMPの2本立て。スキルはMPを使う（M3）
- **装備の必要条件**：装備には必要レベルがある。能力値の必要値は、振り方を縛らないよう**神話（赤）の武器だけ**（武器の主能力）
- **落ちる装備のレベル**：波の数が基本で、**自分のレベル＋3が上限**（レベルが波に追いつかなくなっても、付けられる装備が落ち続ける）
- **装備の効果**：STR+3 のような能力値の効果も付く
- **副能力**：職業ごとに主能力（1ポイントで攻撃力+2%）と副能力（+1%）を持つ。灯術師 INT/WIS、影刃 STR/DEX、灯番 WIS/VIT。武器によって入れ替わるものもある（短剣は DEX が主・STR が副。神話の短剣の必要値も DEX）。3次職は攻撃力が伸びる能力値がもう1つ増える（+1%／ポイント。焔王 DEX・星守 VIT・日蝕 INT・血の君主 VIT・暁光 INT・神盾 STR）
- **振り直し・リセット**：能力値の画面で、振ったポイントを全部戻せる（RESET POINTS）。RESET ALL はその職業を**完全に最初から**やり直す（レベル・能力値・スキルの熟練度・持ち越した装備と倉庫・火種・最深層をすべて消す）。どちらも2回押しで実行
- **後の段階で作るもの**：スキルの習得と強化（M3）、町とNPC・転職（M5）

### 4.5.4 ボスと Mythic 装備【決定・数値は案】
- 試作の波では **10波ごとにボス**（大きく硬い：同じ波の雑魚の120倍の体力・2.5倍の攻撃。約3.4秒ごと（怒ると2秒ごと）に力をためて周りを叩きつける。赤い輪が広がりきった瞬間に当たる）。お供の雑魚は普段の半分
- **区域ごとのボス**（5層ごと、その区域の最後の層）。どの攻撃も予告（赤い範囲・扇、全体攻撃は緑の安全な円）のあとに判定。体力が半分を切ると怒って速くなり、予告と間隔が短くなる
  - 灰の番人（灰の回廊）：たたきつけ・突進
  - 苔の母（苔むす底）：胞子の弾の輪（攻撃力ダウン）・手下のスライムを呼ぶ・たたきつけ
  - 炉の巨人（残り火の炉）：扇状の炎の息（防御ダウン）・たたきつけ
  - 霜の王（凍てる墓所）：凍結の波（気絶）・氷の弾の扇（鈍足）
  - 書庫の司書（沈んだ書庫）：全体攻撃（攻撃力ダウン）・弾の輪と扇。距離を取り、近づかれると離れた場所へ瞬間移動
  - 虚ろの影（虚ろの淵）：全体攻撃（防御ダウン）・扇（攻撃力ダウン）・気絶の波・プレイヤーのそばへ瞬間移動
- **弱体効果**：気絶（動けず攻撃もスキルも出ない）・鈍足（移動半分）・攻撃力ダウン（-25%）・防御ダウン（-40%）。強化と並べて赤い縁のアイコンで出す
- 倒すと大きなドロップの噴水。**30%で Mythic（赤）装備**が落ちる（黄金のスライムは 10%、精鋭は 3%）
- Mythic 装備：効果4つ＋通常の固有効果1つ＋ボス専用の固有効果1つ（回避で炎が弾ける／25%でもう一度攻撃／与えたダメージの1%回復）
- M4 で層を作るときは、各層の最後のボスとして作り直す

### 4.5.5 スキル【決定・数値は案】
- **各職業6つ**。Lv1・5・10・18・26・35 で**自動で覚える**
- **使うほどスキルレベルが上がる**（熟練度。最大10）。1つ上がるごとに威力・回復量・効果 +10%、待ち時間 -3%
- 画面下のボタンは3つ。覚えたスキルからスキルの画面で選んで付ける。ボタンごとに**手動／オート**（オートは使って意味のあるときだけ使う：範囲に敵がいる、体力が減っている など）
- MP を使う。効果は6種類：周りに当たる／まとめて撃つ／突進して斬る／狙った場所に遅れて落ちる／一定時間の強化／回復

| 職業 | スキル（覚えるレベル） |
| --- | --- |
| 灯術師 | Flame Ring(1)・Fire Barrage(5)・Flare(10)・Meteor(18)・Ember Shield(26)・Inferno(35) |
| 影刃 | Whirlwind(1)・Shadow Dash(5)・Frenzy(10)・Crescent Wave(18)・Second Wind(26)・Thousand Cuts(35) |
| 灯番 | Holy Pulse(1)・Mend(5)・Lantern Ward(10)・Kindle(18)・Flame Pillar(26)・Judgment(35) |

### 4.5.6 明るさと暗闇・精鋭（M3b）【決定・数値は案】
- 部屋全体を暗くし（シーンの全体の光を弱める）、プレイヤーのランタンの光だけで照らす。光の広さ＝明るさ
- 火の玉・斬撃・爆発・ドロップ・光の柱は、暗闇でも光って見える（光の影響を受けない素材）
- 精鋭：第3波から、たまに出る。大きく、色が違い、体力4倍。倒すと小さなドロップの噴水と多めの経験値
  - Swift（速い）／Hardened（とても硬く、遅い）／Splitter（倒すと3体に分裂）／Shroud（近くにいる間、こちらの明るさを2奪う。灯術師の射程が縮む）
- ボスは体力が半分を切ると怒る：動きが速くなり、叩きつけの間隔が短くなる

### 4.5.7 塔の層（M4a）【決定・数値は案】
- **終わりなし**の塔。下りるほど敵とドロップが強くなる（尺度は「層×2」）。職業ごとに**最深層**を記録する
- 各層は48×48マスの迷宮：ランダムに並べた部屋（5〜8部屋。深いほど多い）を幅2の廊下でつなぐ。はじめの部屋は安全
- 部屋に入るとその部屋に敵が出る。敵は迷路を回り込んで追ってくる。部屋の敵を全滅させると小さなドロップの噴水
- 階段は、はじめの部屋から一番遠い部屋。乗ると「帰還する／下りる／とどまる」を選ぶ（帰還の内容は 4.5 の試作の形と同じ）。下りるときは、地面のドロップを拾える分だけ拾う
- **5層ごとにボスの層**：はじめの部屋 → 廊下 → 大きなボスの部屋。ボスを倒すと階段が現れる
- 右上に小さな地図（見た場所だけが出る。自分と階段の位置）
- **区画**：塔は下へ下りていく。5層ごと（ボスを倒すたび）に区画が変わり、床・壁の色と模様、全体の光の色、背景、スライムの色が変わる。新しい区画に入ると名前を大きく出す
  - 1〜5 Ashen Halls（灰の回廊）／6〜10 Mossy Depths（苔むす底）／11〜15 Ember Forge（残り火の炉）／16〜20 Frozen Crypt（凍てる墓所）／21〜25 Sunken Archive（沈んだ書庫）／26〜30 Void Hollow（虚ろの淵）。31層からは「II」として少し暗くして繰り返す
- **チェックポイント**：ボスを倒すと、その次の層（6・11・16…）から始められるようになる（職業ごと）。職業を選んだあと、開始する層を選ぶ
- **祭壇（M4b）**：普通の層には祭壇が1つ（地図に橙の点）。乗ると、ランダムな3つの加護から1つを火種を払って選ぶ（1層で1回。値段は 25 + 層×12）。加護はその挑戦のあいだずっと効き、重ねがけできる（12種類：ダメージ、攻撃速度、明るさ、会心率、会心ダメージ、最大体力、MP、移動速度、防御、吸収、弾の数、撃破時の爆発）
- **中断と再開（M4b）**：層に入ったとき・アプリが裏に回ったとき・閉じたときに、挑戦の状態（層・装備・鞄・火種・加護・体力とMPの割合）を自動で保存。職業を選ぶと「CONTINUE」で、その層の最初から続けられる。死亡・帰還・新しく始めたときは消える

### 4.6 敵（初回は8種類＋精鋭の変化＋ボス1体）
- 【できた】5種類：スライム（まっすぐ追う）・コウモリ（速く、ふらふら飛ぶ。体力少なめ）・術師（距離を取って緑の弾を撃つ）・岩鬼（硬い。赤く点滅して力をためたあと突進）・爆弾虫（近づくと導火線に火がつき、赤い輪の範囲で爆発。爆発すると経験値もドロップも出ない）
- 【できた】敵は層に入った時点で全部の部屋に置かれ、部屋に入るまで眠っている（その場でゆっくり揺れるだけ）。部屋に入るか、外から攻撃されると、その部屋の敵がみんな起きて動き出す。部屋を片付けたかは、その部屋の敵だけで判定する
- 眠っている敵は、攻撃（自動の狙い・斬撃・回る灯り・弾・スキル・爆発）の対象にならない（壁ごしに隣の部屋を起こさない）。部屋は 9〜13マス四方で、部屋どうしは6マス以上離す（迷宮は64マス四方）。眠った敵は部屋の中央寄りに置く
- 【できた】**段階（下級・中級・上級）**：どの種類にも3段階。上級ほど角・牙・光る目が付き、色が暗く、少し大きく厳つくなる
  - 強さ（下級／中級／上級）：体力 0.8／1.25／1.9倍、攻撃 0.85／1.1／1.3倍、速さ 0.95／1.05／1.12倍、経験値 0.8／1.3／2倍
  - 出る割合は層で変わる：1層はほぼ下級（中級が3割）、30層あたりで下級4割・中級4割・上級1割、60層で上級3割強、100層では上級6割
  - ボス・黄金のスライム・分裂した子は段階なし
- 【できた】**黄金のスライム**：部屋に入ったとき 6% で一緒に出る（ボスの部屋は除く）。当たってもダメージはなく、逃げ回り、12秒で消える（最後の2秒は点滅）。体力はスライムの6倍。倒すと装備10個（珍しさが出やすい）と火種の噴水、経験値10倍
- 【できた】**宝の間**：ボスの層以外で 15% の層に1つ。敵が出ない部屋に宝箱が3つ並び、近づくと開いて、装備4個（珍しさが出やすい）と火種の噴水
- 区画ごとに出る割合が変わる（灰の回廊はスライム・コウモリ・岩鬼、苔むす底は術師と爆弾虫も、残り火の炉は岩鬼と爆弾虫が多い、凍てる墓所は術師が多い、虚ろの淵は全部が同じ割合）。精鋭はどの種類にも付く
- 群れの雑魚：数で押してくる。倒すと気持ちよく弾ける
- 明るさと関わる敵：影法師（明かりの外でしか動かない）、蛾（明るいほど群がる）、闇撒き
- 精鋭：通常の敵に「速い」「硬い」「分裂する」などの性質が付いた強い敵。ドロップの噴水が出る
- ボス：塔の底の「消えない炎」

### 4.5.7b キャラクターの枠【決定】
- キャラクターは **3つの枠** に保存する。空いた枠を選ぶと、好きな職業で新しく作れる。**同じ職業を複数作ってよい**（例：灯術師を2人作り、炎呼びと灯台守に育てる）
- 職業の選択は職業の数に合わせて並べる（職業が増えても入る）
- 枠ごとに：レベル・能力値・スキル・上位職・3次職・装備・持ち込みの品・火種・最深層・中断した挑戦。倉庫だけは全キャラクターで共有
- キャラクターは「消す」（2回押し）で消せる。前の版の保存データ（職業ごとに1人）は、読み込み時に枠1〜3へ順に入る
- 町の「キャラ選択」で、ほかのキャラクターに切り替えられる

### 4.5.8 町（M5）【決定・数値は案】

- 出撃：開始する層を選んで塔へ（チェックポイント・中断した挑戦がなければ1層から）
- **倉庫番**：選んだ品は、移す・ロック／ロック解除・**売却**（火種になる）・**破棄**（消すだけ）ができる（売却・破棄は2回押し、ロック中はできない）。倉庫（**全職業で共有**・60個）と「次の挑戦に持ち込む品」（職業ごと・24個）の出し入れ、町での分解。ほかの職業の武器は持ち込めない（倉庫経由で別の職業へ渡す用）
- **商人**：回復薬（体力40%回復）・魔力の薬（MP50%回復）を各99個まで（1個ずつか10個まとめて買える）。値段は 20＋最深層×2。装備の箱（その職業・今のレベルの「稀」以上がランダム1つ）150＋レベル×8

- 転職すると **Lv1 に戻る**（経験値0、振った能力値も戻る）。ボーナスとして **30ポイント**を振れる。スキルの熟練度・装備・火種・最深層はそのまま。必要レベルに届かない装備は、転職したときに外れて倉庫へ送られる（倉庫がいっぱいなら、挑戦の始めに外れて鞄へ）

  - 強化すると、金床を叩く「カン、カン」という音と、品の名前のあたりで火花が散る演出（白く光り、「+5」のような文字が跳ねる）
  - 珍しさの倍率：並0.5・良0.7・稀1・伝承1.5・灯宝2・神話3

- 薬は挑戦中に右下の HP／MP ボタン（PC は Q／E）で使う。1秒の待ち時間。死んでも使っていない薬は残る
- 支払いはすべて、その職業が持ち帰った火種

### 4.5.10 装備の効果（M6）【できた・数値は案】
- 効果は **27種類**：ダメージ%・攻撃速度%・会心率・会心ダメージ・移動速度%・最大体力・最大体力%・防御・明るさ・貫通（灯術師だけ）・弾/灯り/斬る数・STR・DEX・INT・VIT・WIS・全能力値・最大MP・体力回復・MP回復・吸収・被ダメージ軽減（60%まで）・HIT・EVA・**幸運**（経験値・拾う火種・珍しい品の出やすさが、まとめて +%）。固有効果は6種類
- **部位ごとに付く効果**（能力値＝STR・DEX・INT・VIT・WIS・全能力値は、どの部位にも付く）
  - 武器：攻撃力 +N（基礎攻撃力に足す。倍率の前）・ダメージ%・攻撃速度%・会心率・会心ダメージ・HIT
  - 防具：最大体力・最大体力%・防御・被ダメージ軽減・吸収・EVA
  - ランタン：最大MP・MP回復・体力回復・移動速度%・明るさ・貫通（灯術師だけ）・弾/灯り/斬る数
  - 指輪：幸運
- 整理で出なくした効果：精鋭・ボスへのダメージ、スキルのダメージ、スキルの待ち時間、スキルの範囲、回避の待ち時間、撃破時の爆発。前の版の装備に付いている分は効き、鍛冶屋の再抽選で消える
- 前の版の「経験値・拾う火種・珍しい品」は、読み込み時に「幸運」1つにまとまる（いちばん大きい値）
- 全能力値・吸収は出にくい。鍛冶屋の強化で値が伸びる（弾・貫通の数は除く）

### 4.5.11 命中と回避（HIT・EVA）【できた・数値は案】
- **HIT**＝DEX＋装備の「HIT」、**EVA**＝DEX＋装備の「EVA」
- 近距離の攻撃（影刃の斬撃、灯番の回る灯り・周りを焼く攻撃）は、HIT と敵の回避で外れることがある（当たる確率 60%〜100%）。遠距離の火の玉とスキルは必ず当たる
- 敵の体当たりと術師の弾は、EVA と敵の命中で避けられる（上限60%）。さらに**囲まれ補正**：2マス以内の起きた敵が1体なら100%、1体増えるごとに -20%、6体以上で0%。爆弾虫の爆発とボスの叩きつけは避けられない
- 外れた・避けたときは「MISS」（避けたときは水色で頭の上に）
- 敵は出たときに命中と回避を持つ：層の深さ × 種類（コウモリ・黄金は避けやすい、岩鬼は当てやすく避けにくい、術師は当てやすい）× 段階（上級ほど高い）。精鋭の俊足は回避が高い。ボスは命中が高く回避は低め
- 能力値の画面に HIT・EVA と、今の層での確率を出す。回避ボタンは緊急ステップとして残す

### 4.5.9 塔の高さ【決定】
- 塔は **100層まで**。100層は最後のボス。倒すと「塔を制覇した」と出て、階段では帰還だけができる（下りるは出ない）。チェックポイントも96層まで

## 4.7 音【仮】
- BGM は最初「区画ごと」：5層ごとの区画に合わせて曲が変わる（灰の回廊：鐘と遠い太鼓／苔むす底：笛としずくの分散和音／残り火の炉：重い低音と金床の刻み／凍てる墓所：高い鐘、太鼓ほぼなし／沈んだ書庫：異国風の音階の笛／虚ろの淵：四つ打ちと矩形波）。ボス戦はその区画の曲を速く激しくした編曲。曲の切り替えは、いったん音を小さくしてから
- 町（層の選択も含む）では町の曲（明るい長調の笛とはじく分散和音）。塔から戻ると切り替わる
- タイトル画面では専用の曲（ゆっくりした笛の旋律と広がる和音）。テーマの設定に関係なく流れる
- 固定のテーマも選べる（Nocturne：暗く静か／Wayfarer：ファンタジーMMO風／Neon Descent：ノリの良いシンセ）。それぞれ通常とボス戦の2曲。方向は「スタイリッシュ」。コードで作ったオリジナルのループ（重ねた鋸波の和音・ディレイ。音量や音程の揺れは控えめ）。N キーか職業選択の画面で切り替え、選んだテーマは保存。M キーでオン／オフ
- 効果音もコードで作った仮のもの。本番の音ができたら差し替える

## 4.9 言語【決定】
- 英語と日本語を切り替えられる。**最初は英語**

- 日本語のフォントはあとで登録する（それまでは日本語が □ で出ることがある）

## 5. 見た目【決定：16×16で一旦進める】

- 【決定】**クォータービュー**（斜め見下ろし）。床は 32×16 ドットのひし形、キャラクターは 16×16 ドット。ゲームの計算は平面の座標で行い、描く位置だけを斜めに変換する
- 操作は画面の向きに合わせる（上を押すと画面の上へ進む）
- 縦画面の内部の解像度は 180×390 前後。横に約11マス見える
- 光の表現：URP の 2D Light でランタンの光と暗闇を描く。ドロップの光の柱もここで表す
- 画面比率が機種ごとに違うため、余白は背景で埋め、ドットがにじまない整数倍で拡大する

| 大量の敵と弾 | 生成・破棄をくり返さず使い回す（オブジェクトプール）。当たり判定は簡単な円同士で計算する。数百体で重いときは処理方式を見直す |
| 大量のドロップ | 画面上のドロップは上限を決め、古い並の装備から火種に変える |
| 装備 | 効果の定義を ScriptableObject で作り、拾った装備は「種類＋珍しさ＋付いた効果と数値」のデータで持つ |
| マップ | Tilemap。部屋を並べて廊下でつなぐ方式。乱数はシード指定可 |
| 入力 | Input System。タッチ、キーボード、ゲームパッド |
| 保存 | 解放の状態・倉庫・中断した層の情報を JSON で保存 |
| 性能 | 中くらいのAndroid端末で、敵100体前後でも60fpsを目標 |
