# ゲームプラン v0.1（ゼロからの再検討）

作成：2026-11-10　状態：検討稿。【決定】はユーザーが選んだもの、【案】は提案で未確定。

## 0. 前提

- 【決定】ジャンル：ローグライク
- 【決定】エンジン：Unity（PC向け）
- 【決定】規模：小さく1本。全体で約1時間遊べる内容
- 【決定】旧作『竜血の旅路』のコード・設定・計画は使わない（削除済み）

## 1. コンセプト【案】

**仮題：『灯守（ひもり）』**

> 灯りは命であり、視界であり、通貨でもある。

光の届かない塔を、ランタンひとつで下っていくターン制のローグライク。
ランタンの「灯」が次の3つを兼ねている。

1. **HP**：攻撃を受けると灯が減り、0になると死亡する
2. **視界**：灯が多いほど周囲が広く見える。減ると暗くなり、敵や罠に気づきにくくなる
3. **通貨**：灯を差し出して、強化や回復と引き換えにする

迷いどころは常に一つ。**「灯を使って強くなるか、残して見通しを保つか」**。

## 2. ゲームの流れ

```
拠点（塔の入口）
 └ 出撃 → 第1層 → 第2層 → 第3層 → 第4層 → 最下層（ボス）
            各層：探索 → 敵・罠・宝 → 祭壇（灯と交換） → 下り階段
 └ 死亡／クリア → 拠点へ戻る（持ち帰った「残り火」で恒久的な解放）
```

| 項目 | 目安【案】 |
| --- | --- |
| 1回の挑戦 | 10〜15分 |
| 初クリアまで | 3〜5回の挑戦（合計約1時間） |
| 層の数 | 5層（4層＋ボス層） |
| 1層の広さ | 部屋6〜9個のランダム生成 |

## 3. 主な仕組み【案】

### 3.1 ターン制グリッド
- プレイヤーが1マス動くか1回行動するごとに、全ての敵も1回行動する
- 移動は上下左右の4方向（斜めを入れるかは要判断）
- リアルタイムにしない理由：灯と視界の駆け引きを落ち着いて考えられるようにするため。作るのも調整するのも楽

### 3.2 灯（ライト）
- 最大値100から始まる。視界の半径は灯の量で段階的に変わる（例：70以上で5マス、40以上で4マス、20以上で3マス、それ未満で2マス）
- 階段を下りるたびに灯が少し減る（同じ層に留まりすぎないための圧力）
- 回復する手段：燭台を拾う、敵を倒すとまれに落ちる「火種」、祭壇での交換

### 3.3 祭壇（各層に1つ）
- 灯を差し出し、3つの「刻印」から1つ選ぶ
- 刻印の例
  - 影歩き：暗い場所にいるあいだ、敵に気づかれにくい
  - 焦がし：攻撃時に灯を5使い、威力が2倍になる
  - 蛍：倒した敵が小さな光を残し、周りを照らす
  - 鏡：受けたダメージの一部を反射する
- 刻印は1回の挑戦のあいだだけ有効。初回は12種類程度

### 3.4 敵（初回は6〜8種類＋ボス1体）
- 闇に強い敵、光に寄ってくる敵、灯を盗む敵など、**灯と関わる性質**を持たせる
- 例：灯喰い（隣にいると毎ターン灯を吸う）、影法師（視界の外でしか動かない）、蛾（灯が多いほど寄ってくる）
- ボス【案】：塔の底にある「消えない炎」。プレイヤーの灯が少ないほど弱くなる。最後に「灯をあえて減らす」判断をさせる

### 3.5 恒久的な解放（ゆるめに）
- 死亡時、その挑戦で拾った「残り火」を持ち帰る
- 拠点で、新しい刻印を祭壇に出るようにしたり、開始時の道具を選べるようにしたりする
- 能力値を直接上げる成長は入れない（腕と知識で上達するゲームにする）

## 4. 見た目と音【案】

- 2Dの見下ろし視点、ドット絵（16×16または32×32のタイル）
- 光の表現が主役：Unityの URP 2D Light で、ランタンの光と周囲の暗闇を描く
- 音は少なめ。火のはぜる音と足音を中心にする

## 5. 技術方針【案】

| 項目 | 方針 |
| --- | --- |
| Unity | Unity 6 LTS 系、URP（2D Renderer） |
| マップ | Tilemap。部屋を並べて廊下でつなぐ方式で生成する。乱数はシード指定できるようにする |
| データ | 敵・刻印・道具は ScriptableObject で定義する |
| ターン処理 | プレイヤー → 敵の順に処理する TurnManager を1つ置く |
| 保存 | 恒久的な解放の状態だけを JSON で保存する（挑戦の途中は保存しない） |
| 入力 | Input System。キーボードとゲームパッド |

想定するフォルダ構成：

```
Assets/
  Scripts/  Core/（ターン・乱数）  Map/（生成）  Actors/（プレイヤー・敵）  Light/  UI/  Meta/（解放・保存）
  Data/     Enemies/  Marks/（刻印）  Items/
  Art/  Audio/  Scenes/（Title, Hub, Run）
```
