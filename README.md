# 竜血の旅路 ～ Dragon Blood Saga ～

『ブレス オブ ファイア』風のブラウザRPGです。HTML / JavaScript だけで動き、ビルドや依存パッケージは不要です。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ローカルサーバーで配信しても動きます）。

| 操作 | キー |
| --- | --- |
| 移動 / カーソル | 矢印キー（WASD も可） |
| 決定 / 調べる / 話す | Z・Enter・Space |
| メニュー / キャンセル | X・Esc |

スマートフォンなどのタッチ端末では、画面の下に仮想パッドが表示されます。

## BoF風の要素

- **竜変身**: 洞窟で「遺伝子」を手に入れると、戦闘中に竜へ変身できます。変身中は能力が大きく上がり、全体攻撃の「ブレス」も使えます。そのかわりターンごとに AP を消費します。
  - 炎の遺伝子 → フレイムドラゴン / 雷の遺伝子 → サンダードラゴン / 両方 → ツインドラゴン
- **個性のある仲間**: 翼をもつ魔法使いミーナ、獣人の格闘家ガロ。
- **フィールドアクション**: ガロが仲間にいると、道をふさぐ大岩を砕けます。
- **釣り**: 村の池にある看板の前で釣りができます。釣った魚は回復アイテムになります。
- **コマンドバトル**: 素早さ順のターン制。属性弱点、会心の一撃、防御、逃走があります。
- 宿屋（全回復とセーブ）、道具屋（消耗品と装備）、メニューからのセーブ（localStorage）

## 構成

```
index.html     画面とタッチパッド
style.css
js/data.js     スプライト・キャラ・魔法・アイテム・敵・マップのデータ
js/engine.js   入力・効果音・描画ヘルパー・ウィンドウ/メニュー・会話・シーン管理
js/battle.js   戦闘シーン
js/main.js     ゲーム状態、フィールド、イベント、メニュー、ショップ、釣り、タイトル
```

マップは `js/data.js` の文字列で定義しています（`.` 草、`T` 木、`~` 水、`R` 岩 など）。マップや敵、アイテムを足すときは、このファイルを編集すれば反映されます。
