# Vivid of Fade（ヴィヴィッド・オブ・フェイド）

Unityで作るAndroid・PC向けの小規模なローグライク・ハクスラ。

- 計画書：[docs/GAME_PLAN.md](docs/GAME_PLAN.md)
- Unityプロジェクトの作り方：[docs/SETUP.md](docs/SETUP.md)（プロジェクト本体は `Game/`）
- 現在の段階：M4a（塔の層：迷宮・階段・5層ごとのボス）の試作。`Game/Assets/Scenes/SampleScene` を開いて Play すると始まる

## 試作の操作（PC・エディタ）

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印（スマホは画面を押してずらす） |
| 回避 | Space（スマホははじく） |
| 攻撃モード切替 | T（自動 ⇔ 押している間だけ） |
| 攻撃（押している間だけ、のとき） | J / 右クリック |
| 鞄 | B / Tab（閉じるのは Esc も可） |
| スキルを使う | 1 / 2 / 3（画面左下のボタン） |
| 回復薬／魔力の薬 | Q / E（画面右下の HP／MP ボタン） |
| スキルの画面（ボタンに付ける） | K |
| 能力値（ポイントを振る） | C |
| BGM のオン／オフ | M |
| BGM のテーマを変える | N（職業選択の画面のボタンでも） |
| 操作の一覧 | H |
| メニュー（鞄・能力値・スキル・設定） | Esc（右上の MENU でも） |
| 言語（英語／日本語） | メニューか職業選択の画面の Language |
| 職業を選ぶ | 1 / 2 / 3（またはボタンを押す）。選ぶと町へ |
